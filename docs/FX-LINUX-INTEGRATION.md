# FX Linux integration

Fenix Night Light is developed as a component of the upcoming **FX Linux** system.

The project is intentionally usable outside FX Linux. FX Linux integration should package and configure the same public core rather than maintaining a private fork.

Expected FX Linux defaults may include:

- privacy-first manual location setup,
- 4500 K daytime temperature,
- 4000 K nighttime temperature,
- 30-minute smooth sunrise/sunset transitions,
- automatic backend selection.

These are policy defaults, not hard-coded assumptions about a user's location or distribution.
